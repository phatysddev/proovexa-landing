# Proovexa landing page
Buildless HTML/CSS/JavaScript in `dist/`.

Preview: `python3 -m http.server 4173 --directory site/dist` from project root.
Deploy `dist/` to any static hosting provider. No dependencies or build step.

The Pilot CTA anchors to details. Registration is explicitly not open. Workspace, code and results are labeled illustrative. No data is collected.
Fonts load from Google Fonts. Theme preference is stored locally when browser storage is available.

## Production SEO
Canonical origin: https://proovexa.tech/. Includes Thai title/description, Open Graph, Twitter summary card, Organization/WebSite/WebPage JSON-LD, robots.txt and sitemap.xml. Logo files are the supplied originals; no generated replacement artwork.
Before launch: serve this directory publicly at proovexa.tech over HTTPS, configure permanent redirects from HTTP and www to the canonical origin on the chosen host, verify the domain in Google Search Console and submit https://proovexa.tech/sitemap.xml. This repository does not change DNS, hosting redirects, or submit to Search Console. No verification token is invented.
